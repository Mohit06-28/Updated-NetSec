Frequently Asked Questions

What is a network scanner?

A network scanner is a tool that probes a target host or IP range to identify live hosts, open ports, and the services running on them. Our online network scanner performs TCP connect scans from the cloud, so nothing needs to be installed locally.

Is the port scanner free?

Yes. The core network scanner and port scanner are 100% free. Just create an account (no OTP required) and start scanning.

How do I scan open ports on my own server?

Login, go to the Port Scanner page, enter your server's public IP or hostname, and click Start Scan. The scanner will return every open TCP port plus its identified service.

Can I scan private IP addresses like 192.168.1.1?

Because the scanner runs in the cloud, it can only reach public IP addresses. Private LAN addresses (10.x, 172.16–31.x, 192.168.x) are not reachable from the internet — you would need to self-host the scanner for internal scanning.

Is this legal to use?

Only scan systems you own or have explicit written permission to test. Unauthorized port scanning is illegal in many jurisdictions. By using this service you agree to the Terms of Service.
